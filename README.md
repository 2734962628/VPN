## 快速开始

1. [创建账户](https://sg.kennysoftware.com/auth/register.php)（未开通套餐也可先登录查看状态）
2. 在门户内购买套餐，或输入已购卡密激活  
   支持 **PayPal**、**微信**、**支付宝**
3. 安装对应客户端
4. 在连接页扫码或复制链接导入

```text
注册 → 开通授权 → 安装客户端 → 扫码导入
```

## 线路

| 线路 | 说明 |
| :--- | :--- |
| **Gost Reality** | 推荐日常。VLESS + Reality，香港入口 → 新加坡出口 |
| **CN2 特快专线** | 按流量单独计费，与套餐时长互不影响 |
| **ISP 住宅线路** | 新加坡高可信度 ISP 出口，独立额度 |
| **经典中继** | 香港中继 → 新加坡，用于对照或主线路异常时切换 |
